# badmintonlab_game

Isaac Lab task package for shared-policy Booster T1 badminton self-play.

Install in editable mode from a complete BadmintonLab-Game checkout:

```bash
python -m pip install -e source/badmintonlab_game
```

Isaac Lab must already be installed in the active Python environment. Robot
assets live in the checkout's `robots/T1/` directory and are not bundled in this
Python distribution. See the repository's root README for training and playback.
